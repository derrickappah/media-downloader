# Media Downloader - Chrome Extension (Manifest V3)

A fast, reliable browser extension to discover, preview, filter, and download media (images, videos, audio, SVGs, canvas graphics, and streams) from any webpage.

---

## Features

- **Multi-Format Media Detection**: Detects `<img>`, `<video>`, `<audio>`, `<picture>`, CSS background images, SVG vectors, Canvas graphics, and media links.
- **Deep Scan**: Auto-scrolls the active page to trigger and capture lazy-loaded assets.
- **ZIP Archiving**: Download selected media files packaged into a single compressed `.zip` file.
- **CSV Export**: Export all detected media links, file types, and dimensions to a spreadsheet.
- **Stream Sniffer**: Discovers `.m3u8` and adaptive video/audio stream URLs.
- **Interactive Preview & Zoom**: Zoom in/out and drag-to-pan high-resolution images in the modal.
- **Filter & Search**: Search by name, extension, URL, or minimum dimensions to exclude small icons.
- **Dark & Light Themes**: Clean theme toggle with Dark, Light, and System Default options.
- **Organized Downloads**: Group downloads into website-specific subfolders (`Downloads/Media_domain.com/`).

---

## Installation & Setup

1. Open **Google Chrome** (or Edge, Brave, Opera) and navigate to `chrome://extensions`.
2. Turn on the **Developer mode** toggle in the top-right corner.
3. Click **Load unpacked** (top-left) and select this directory.
4. Click the **Media Downloader** icon in your browser toolbar to scan and download media.
